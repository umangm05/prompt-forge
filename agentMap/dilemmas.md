# Dilemmas & Battlefield Signs

**Status:** built — tactical conversation redesign

## Core finding
Fun when each turn creates a new problem that changes the next turn.
Boring when turns only resolve actions and nudge numbers.

Primary objective each turn: **create or solve a dilemma** — and expose enough causal information that multiple plans can emerge. The engine never enumerates the player's choices.

## Identity
PromptForge is an **emergent tactics game** where language is the controller — not a prompt-engineering contest. Combat is also **tactical information warfare**: reshape the field *and* the opponent's beliefs.

## Boss requirements
- Clear **goal** + **signature toolkit** (plasma cutter, chalk, short blade, both hands…)
- Every intent answers **with what?**
- Visible **commitment before player input**
- Fallible **beliefs** from observables only (never private player text)
- Defining **flaw** that can force emotional mistakes
- 2–4 **signature moments** with tells, self-risk, and aftermath
- Visible plan progression (weaken → sag → fail) via `TacticalThread`

## Show facts, never advice
Good:
```
Battlefield
• ⚠ Damaged Railing (3)
• The railing groans. Rust flakes fall as the metal begins to bend.
• Omen — Structural Collapse: Hairline cracks spider across a support.
```

Bad:
```
Now you face
• Choose between moving… or disabling…
```

Discovery is gameplay. Temptations appear as fiction pressure, never safe/risky menus.

## Damage
Every Body/Resolve change needs an obvious narrative cause.
Players remember the collapsing bridge — not “-8 Resolve.”

## Tempo
Beats move among lull / pressure / rupture / aftermath. Quiet turns still reveal tells, omens, or false signals. Explosive turns spend buildup.
