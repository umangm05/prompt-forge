- LEARNED list from experiments

- Tips/?, HELP×2, autofill-off inputs
- Boss speech opens after dossier close (and on duel start with commitment)
- Boot modal footer: **MORE_FROM_US** links to the other helper sites (`src/ui/moreFromUs.ts`; owner decision D-HELPER-SITES-CROSSLINK — every helper site links to the others; Tiny Worlds 3D added once it has a URL)

## Conventions
- Never solve the puzzle in copy (“choose between…”)
- Show sensory facts; trust players to infer
- Do not expose private boss belief truth (`correct|mistaken`) — only observable tells
